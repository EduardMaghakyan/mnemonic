## Mnemonic v0.3.1

A small follow-up to v0.3.0. No behaviour changes for existing users — if you don't see the tray difference, there's nothing to do.

### What changed

- **Tray menu cleanup.** Removed the "Grant Microphone Access…" item. macOS already prompts for microphone permission on first recording (via `AVCaptureDevice`), mirroring how Screen Recording is handled — the dedicated tray shortcut was asymmetric and rarely needed. If the mic is denied after first-use, the on-denial notification now points you straight to *System Settings → Privacy & Security → Microphone*.

### Install

```bash
brew upgrade --cask mnemonic
```

Or download `Mnemonic_0.3.1_aarch64.dmg` below.

### Requirements

Unchanged from v0.3.0.

- Apple Silicon Mac (M1 or later)
- macOS 13 Ventura or later
- `llama.cpp` 9050+
- 16 GB unified memory minimum

### Upgrading from v0.2.x

If you're skipping v0.3.0, read the [v0.3.0 release notes](https://github.com/EduardMaghakyan/mnemonic/releases/tag/v0.3.0) — image attachments, the recording queue, and intent routing all landed there.
